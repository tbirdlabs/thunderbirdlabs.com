# thunderbirdlabs.com

Source for [thunderbirdlabs.com](https://thunderbirdlabs.com), home of Thunderbird Labs' open-source hardware projects.

The build files themselves (CAD, printable parts, firmware) live in each project's own repository and on [Printables](https://www.printables.com/@Thunderbird_37724). This repository is just the website.

## Layout

Plain HTML and CSS with no build step, hosted on GitHub Pages straight from `main`.

```
index.html     home page
clotho.html    Clotho eSpinner project page
calliope.html  Calliope project page
style.css      shared styles
images/        web-sized images
```
